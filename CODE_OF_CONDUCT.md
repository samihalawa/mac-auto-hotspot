# Code of Conduct

Be respectful and constructive. Harassment, personal attacks and discrimination are not
accepted in issues, pull requests or discussions. This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report problems through a private [security advisory](https://github.com/samihalawa/mac-auto-hotspot/security/advisories/new).
